## [0.1.0] - 2026-08-10

### Added

- Initial release of `intent-drift` on PyPI.
- Evidence-based intent drift detection engine.
- Pluggable evidence provider architecture (goal, constraints, scope, dependencies, architecture, file graph, execution).
- Explainable alignment reports with overall alignment, status, confidence, and recommendations.
- Public API via `intent_alignment.IntentAlignmentEngine`.
- Comprehensive unit and integration test suite.
